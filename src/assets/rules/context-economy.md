# Context Economy

**Read what the task needs — never the whole.**

- A file over about 40 KB: list its headings first, then read only the ranges you need
- Before printing search matches, list or count them; when a count decides something, confirm the search accepted the pattern — an error means refused, not zero
- Never print a large file whole; page it with offset and limit, and cap any output you print
